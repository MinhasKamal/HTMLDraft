Instructions

You can write, format, and test your HTML, CSS, and JS code here.

As there are no servers, your data is saved in the local storage and never leaves your device. So, it is private, safe, and free for all kinds of usage.

Keyboard Shortcuts

  • Tab / Shift+Tab Smart Indent
  • Ctrl + / Toggle Comment
  • Ctrl + F Find / Search
  • Alt + ↑ / ↓ Move Line Up/Down
  • Ctrl + Z / Y Undo / Redo
  • Ctrl + Click Multi Cursor
  • Atl + Select Vertical or Column Select and Edit

Power Features

  • Smart Indentation: The editor automatically sniffs your code on load to detect indentation: 2-space, 4-space, or Tab. You can also override this.
  • Code Beautifier: Click "Format Code" to clean up messy HTML, CSS, and JS structure following your preferred indentation.
  • Mini Console: Displays console.log() outputs and JavaScript runtime errors. Pops up automatically if your code crashes.
  • Browser Title Bar: Simulates a real browser tab by extracting the <title> and <link rel="icon"> from your code.
  • Auto-Save: Your code is silently saved to your browser's local storage as you type. It will be restored even after you restart your device.
